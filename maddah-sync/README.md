# طنین مداحی – همگام‌ساز هوشمند صوت و متن

نسخهٔ اندروید (APK) با Capacitor ساخته می‌شود و روی **اندروید ۷ و بالاتر** نصب می‌شود.

## قابلیت‌های جدید

- **انتخاب صوت از گوشی**: روی هر اثر (در فهرست آثار یا بالای متن) دکمهٔ «انتخاب صوت» / «تغییر صوت» هست. فایل صوتی داخل حافظهٔ برنامه ذخیره می‌شود و بعد از بستن برنامه هم می‌ماند.
- **به‌خاطر سپردن مکان**: آخرین اثر باز شده و ثانیهٔ توقف هر اثر ذخیره می‌شود. دفعهٔ بعد، برنامه همان اثر را باز می‌کند و روی «ادامه از …» می‌ایستد.
- دکمهٔ برگشت اندروید: ابتدا پنجره‌ها را می‌بندد، بعد به متن برمی‌گردد، بعد برنامه را به پس‌زمینه می‌برد (پخش قطع نمی‌شود).

## ساخت APK با GitHub Actions

1. پروژه را در یک مخزن گیت‌هاب بریزید (شاخهٔ `main`).
2. به تب **Actions** بروید؛ workflow با نام **Build Android APK** با هر push اجرا می‌شود (یا با دکمهٔ *Run workflow*).
3. بعد از پایان (حدود ۵ تا ۱۰ دقیقه) از پایین صفحهٔ اجرا، بخش **Artifacts**، فایل `TaninMaddahi-apk` را دانلود کنید:
   - `TaninMaddahi-release.apk` ← نسخهٔ نهایی امضاشده
   - `TaninMaddahi-debug.apk` ← نسخهٔ آزمایشی
4. با ساخت تگ مثل `v1.0.0` فایل‌های APK به بخش **Releases** هم اضافه می‌شوند.

### امضای ثابت (برای به‌روزرسانی روی نسخهٔ قبلی)

اگر Secret تنظیم نکنید، هر بار با یک کلید موقت امضا می‌شود (نصب می‌شود، اما برای نسخهٔ بعدی باید قبلی را پاک کنید). برای امضای ثابت یک بار کلید بسازید:

```bash
keytool -genkeypair -v -keystore maddahi.keystore -alias maddahi -keyalg RSA -keysize 2048 -validity 10000
base64 -w0 maddahi.keystore   # خروجی را در KEYSTORE_BASE64 بگذارید
```

در **Settings → Secrets and variables → Actions → Secrets** این‌ها را بسازید: `KEYSTORE_BASE64`، `KEYSTORE_PASSWORD`، `KEY_ALIAS`، و (اختیاری) `KEY_PASSWORD`. فایل keystore را هرگز در مخزن نگذارید و یک نسخه از آن را جای امن نگه دارید.

## استخراج هوشمند متن و گوگل درایو

این دو قابلیت به سرور `server.ts` نیاز دارند که داخل APK نیست. اگر نسخهٔ آنلاین برنامه را (مثلاً در AI Studio / Cloud Run) دارید، آدرسش را یکی از این دو راه بدهید:

- داخل برنامه: **تنظیم سرور واسط ← آدرس سرور برنامه**
- یا موقع ساخت: در گیت‌هاب **Settings → Secrets and variables → Actions → Variables** متغیر `API_BASE_URL` را بسازید.

بدون آدرس سرور، بقیهٔ امکانات (پخش، متن، همگام‌سازی دستی، انتخاب صوت، یادداشت) بدون اینترنت کار می‌کنند.

## نکته دربارهٔ اندروید ۷

برنامه داخل WebView سیستم اجرا می‌شود. اگر گوشی به Google Play وصل است، **Android System WebView** را به‌روز کنید (نسخهٔ ۸۴ یا بالاتر)، وگرنه بعضی فاصله‌ها در صفحه کم می‌شود.

## اجرای محلی

```bash
npm install
```
