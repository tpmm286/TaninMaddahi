# طنین مداحی – همگام‌ساز هوشمند صوت و متن

برنامهٔ اندروید برای پخش نوحه و مداحی با **متن همگام با صوت**، استخراج خودکار متن و زمان‌بندی با هوش مصنوعی، ذخیرهٔ آثار و یادداشت‌ها.
نسخهٔ اندروید (APK) با Capacitor ساخته می‌شود و روی **اندروید ۷ و بالاتر** نصب می‌شود.

> برنامه بدون هیچ اثر پیش‌فرضی شروع می‌شود؛ آثار را خودتان اضافه می‌کنید.

## قابلیت‌ها

- پخش صوت با متن همگام، تکرار یک مصراع یا بازه، تغییر سرعت و گام
- **استخراج هوشمند متن و زمان‌بندی** از فایل صوتی یا ضبط میکروفون (با سرور واسط سازگار با OpenAI)
- کپی سریع متن، کپی با زمان (قالب LRC) یا کپی تک‌خط از پیش‌نمایش استخراج
- ویرایشگر همگام‌سازی دستی، نشانه‌گذاری و یادداشت روی هر مصراع، حالت منبر
- انتخاب صوت از حافظهٔ گوشی و به‌خاطر سپردن مکان توقف هر اثر
- پشتیبان‌گیری و بازیابی کامل آثار

## دانلود و نصب

از بخش **[Releases](../../releases)** فایل `TaninMaddahi-release.apk` را دانلود و نصب کنید
(اجازهٔ «نصب از منابع ناشناس» را برای مرورگر یا مدیر فایل فعال کنید).

## تنظیم سرور واسط برای استخراج هوشمند

داخل برنامه: **تنظیم سرور واسط**

| فیلد | مقدار |
|---|---|
| Base URL | آدرس سرور شما، مثلاً `https://your-proxy.vercel.app/v1` |
| API Key | کلید سرور (اختیاری، طبق تنظیم سرور) |
| Model | مثلاً `gemini-2.5-flash` یا نام مدل پشتیبانی‌شده در حساب شما |
| نوع درخواست | «خودکار» یا Chat Completions |

سرور باید سازگار با OpenAI باشد و ورودی صوتی (`input_audio`) را بپذیرد؛
برای مثال [openai-gemini](https://github.com/PublicAffairs/openai-gemini) که Gemini را به قالب OpenAI تبدیل می‌کند.

نکته‌ها:

- برنامه صوت را قبل از ارسال به تکه‌های ۶۰ ثانیه‌ای (مونو، ۱۶kHz) تبدیل و بلندی آن را یکنواخت می‌کند، چون Vercel بدنهٔ درخواست را حداکثر **۴٫۵ مگابایت** می‌پذیرد.
- مسیر `audio/transcriptions` (Whisper) در بسیاری از سرورهای واسط پیاده‌سازی نشده است؛ مدل Gemini با Chat Completions توصیه می‌شود.
- مدل‌های سبک (lite) در رونویسی فارسی دقت کمتری دارند؛ برای دقت بیشتر مدل قوی‌تر انتخاب کنید.
- کلید API فقط روی گوشی شما ذخیره می‌شود.

## ساخت APK با GitHub Actions

1. پروژه را در یک مخزن گیت‌هاب (شاخهٔ `main`) قرار دهید.
2. هر push روی `main` یا اجرای دستی **Actions → Build Android APK → Run workflow** یک APK می‌سازد (۵ تا ۱۰ دقیقه). خروجی در بخش **Artifacts** همان اجرا، با نام `TaninMaddahi-apk` است.
3. برای **انتشار رسمی** تگ نسخه بسازید (راهنمای پایین).

### امضای ثابت (برای به‌روزرسانی روی نسخهٔ قبلی)

اگر Secret تنظیم نکنید، هر بار با کلید موقت امضا می‌شود و نسخهٔ بعدی روی قبلی نصب نمی‌شود (باید اول حذف کنید). یک بار کلید بسازید:

```bash
keytool -genkeypair -v -keystore maddahi.keystore -alias maddahi -keyalg RSA -keysize 2048 -validity 10000
base64 -w0 maddahi.keystore   # خروجی را در KEYSTORE_BASE64 بگذارید
```

در **Settings → Secrets and variables → Actions → Secrets** این‌ها را بسازید:
`KEYSTORE_BASE64`، `KEYSTORE_PASSWORD`، `KEY_ALIAS`، و (اختیاری) `KEY_PASSWORD`.
فایل keystore را هرگز در مخزن نگذارید و یک نسخه از آن را جای امن نگه دارید؛ اگر گم شود نمی‌توانید نسخهٔ قابل‌به‌روزرسانی منتشر کنید.

## انتشار نسخه (Release)

```bash
git tag v1.0.0
git push origin v1.0.0
```

با ارسال تگ `v*` به‌صورت خودکار APK ساخته می‌شود، با همان شمارهٔ نسخه (`1.0.0`) در برنامه ثبت می‌شود و در **Releases** منتشر می‌شود (همراه با فهرست تغییرات خودکار). برای نسخهٔ بعد، شمارهٔ تگ را بالا ببرید (`v1.0.1`، `v1.1.0`).

## نکته دربارهٔ اندروید ۷

برنامه داخل WebView سیستم اجرا می‌شود. اگر گوشی به Google Play وصل است، **Android System WebView** را به‌روز کنید (نسخهٔ ۸۴ یا بالاتر).

## اجرای محلی

```bash
npm install
npm run dev        # نسخهٔ وب با سرور
npm test
```

نسخهٔ وب با `server.ts` می‌تواند استخراج و گوگل درایو را از سمت سرور انجام دهد؛ در APK این بخش‌ها مستقیم از داخل برنامه به سرور واسط می‌روند.

## حریم خصوصی

آثار، یادداشت‌ها و تنظیمات روی دستگاه شما ذخیره می‌شود. فقط هنگام «استخراج هوشمند» صوت (پردازش‌شده) به سرور واسطی که خودتان وارد کرده‌اید ارسال می‌شود.
