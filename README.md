طنین مداحی – همگام‌ساز هوشمند صوت و متن

برنامهٔ طنین مداحی برای پخش نوحه و مداحی با متن همگام با صوت، استخراج هوشمند متن و زمان‌بندی با کمک هوش مصنوعی، ذخیرهٔ آثار و یادداشت‌ها.

- 🌐 نسخهٔ وب (PWA): "اجرای طنین مداحی" (https://tpmm286.github.io/TaninMaddahi/)
- 📱 نسخهٔ اندروید: اندروید ۷ و بالاتر

نسخهٔ وب را می‌توانید در مرورگر اجرا کنید و در مرورگرهای پشتیبانی‌شده، از منوی مرورگر به صفحهٔ اصلی گوشی اضافه کنید.

«برنامه بدون هیچ اثر پیش‌فرضی شروع می‌شود؛ آثار را خودتان اضافه می‌کنید.»

قابلیت‌ها

- پخش صوت با متن همگام، تکرار یک مصراع یا بازه، تغییر سرعت و گام
- استخراج هوشمند متن و زمان‌بندی از فایل صوتی یا ضبط میکروفون، با استفاده از سرویس هوش مصنوعی سازگار
- کپی سریع متن، کپی همراه زمان‌بندی با قالب LRC و کپی تک‌خط از پیش‌نمایش استخراج
- ویرایشگر همگام‌سازی دستی، نشانه‌گذاری و یادداشت برای هر مصراع و حالت منبر
- انتخاب فایل صوتی از حافظهٔ گوشی و به‌خاطر سپردن محل توقف هر اثر
- پشتیبان‌گیری و بازیابی آثار

تنظیم هوش مصنوعی برای استخراج متن

استخراج هوشمند به سرویس هوش مصنوعی خارجی نیاز دارد. برنامه به‌تنهایی سرور پردازش صوت یا اعتبار استفاده از مدل هوش مصنوعی را فراهم نمی‌کند. برای استفاده از این قابلیت، باید یک سرویس سازگار با API موردنیاز برنامه تنظیم کنید.

داخل برنامه، بخش تنظیم سرور واسط را باز کنید و مقادیر زیر را وارد کنید:

فیلد| مقدار
Base URL| آدرس پایهٔ سرویس سازگار با OpenAI
API Key| کلید API صادرشده از سرویس‌دهنده
Model| نام مدل پشتیبانی‌شده توسط سرویس
نوع درخواست| «خودکار» یا Chat Completions، مطابق پشتیبانی سرویس

نمونهٔ تنظیم با Gemini

اگر سرویس و مدل مورد استفاده‌تان از سازگاری OpenAI پشتیبانی کنند، می‌توانید مستندات رسمی "Gemini API" (https://ai.google.dev/gemini-api/docs/openai) و بخش "دریافت کلید API" (https://aistudio.google.com/app/apikey) را بررسی کنید.

- Base URL: نشانی پایه‌ای که سرویس‌دهنده برای API سازگار ارائه می‌کند؛ برای نمونه، "https://generativelanguage.googleapis.com/v1beta/openai/" در صورت پشتیبانی از مسیر موردنیاز برنامه.
- API Key: کلید API خودتان.
- Model: نام دقیق مدلی که سرویس‌دهنده و نوع درخواست انتخابی پشتیبانی می‌کنند.
- نوع درخواست: گزینه‌ای که با API و قابلیت پردازش صوت سرویس سازگار است.

توجه: نام مدل‌ها و قابلیت‌های پشتیبانی‌شده ممکن است تغییر کنند. پیش از استفاده، مستندات سرویس را بررسی کنید. صرفاً وارد کردن یک آدرس و کلید به معنی پشتیبانی قطعی از ورودی صوتی نیست.

برنامه برای استخراج هوشمند به سرویسی نیاز دارد که روش ارسال صوت مورد استفادهٔ آن را پشتیبانی کند. یک API سازگار با OpenAI لزوماً همهٔ مسیرهای صوتی یا همهٔ مدل‌ها را پشتیبانی نمی‌کند.

نکات مربوط به استخراج صوت

- برنامه صوت را پیش از ارسال به بخش‌های ۶۰ ثانیه‌ای تبدیل می‌کند و آن را به مونو با نرخ نمونه‌برداری ۱۶ کیلوهرتز می‌رساند؛ بلندی صدا نیز یکنواخت می‌شود.
- اندازهٔ درخواست ممکن است با محدودیت سرویس‌دهنده روبه‌رو شود؛ در پیاده‌سازی فعلی، محدودیت تقریبی بدنهٔ درخواست ۴٫۵ مگابایت در نظر گرفته شده است.
- مسیر "audio/transcriptions" در همهٔ سرویس‌های واسط پیاده‌سازی نشده است؛ مسیر و مدل مناسب را براساس مستندات سرویس انتخاب کنید.
- کیفیت تشخیص فارسی به مدل، کیفیت ضبط و سرویس‌دهنده بستگی دارد.
- هزینهٔ استفاده از API، محدودیت رایگان و شرایط سرویس را خود سرویس‌دهنده تعیین می‌کند. رایگان بودن کلید API یا سرویس تضمین‌شده نیست.

حریم خصوصی

آثار، یادداشت‌ها و تنظیمات برنامه روی دستگاه شما ذخیره می‌شوند. هنگام استفاده از قابلیت استخراج هوشمند، صوت پردازش‌شده برای ارائهٔ نتیجه به سروری ارسال می‌شود که خودتان تنظیم کرده‌اید.

بنابراین، پیش از ارسال فایل صوتی، شرایط حریم خصوصی و سیاست نگهداری داده‌های سرویس‌دهنده را بررسی کنید. از ارسال محتوای حساس به سرویس‌هایی که به آن‌ها اعتماد ندارید خودداری کنید.

کلید API را محرمانه نگه دارید. اگر نسخهٔ وب کلید را در مرورگر ذخیره کند، این کلید روی همان دستگاه و در همان محیط مرورگر قابل دسترسی خواهد بود؛ کلید را در دستگاه‌های مشترک ذخیره نکنید.

مشکلات و پشتیبانی

اگر سایت باز نشد، ابتدا دوباره نشانی نسخهٔ وب را باز کنید و مطمئن شوید آخرین انتشار GitHub Pages با موفقیت انجام شده است.

اگر استخراج هوشمند کار نکرد، موارد زیر را بررسی کنید:

1. آدرس Base URL و کلید API صحیح باشند.
2. نام مدل در سرویس‌دهنده موجود و فعال باشد.
3. مدل و API انتخاب‌شده ورودی صوتی و روش درخواست برنامه را پشتیبانی کنند.
4. سهمیه، محدودیت درخواست یا شرایط پرداخت سرویس‌دهنده مانع درخواست نشده باشد.

برای گزارش مشکل یا پیشنهاد قابلیت، از بخش "Issues" (../../issues) مخزن پروژه استفاده کنید.
