# طنین مداحی – همگام‌ساز هوشمند صوت و متن

برنامهٔ اندروید برای پخش نوحه و مداحی با **متن همگام با صوت**، استخراج خودکار متن و زمان‌بندی با هوش مصنوعی، ذخیرهٔ آثار و یادداشت‌ها.
نسخهٔ اندروید روی **اندروید ۷ و بالاتر** نصب می‌شود.

> برنامه بدون هیچ اثر پیش‌فرضی شروع می‌شود؛ آثار را خودتان اضافه می‌کنید.

## قابلیت‌ها

- پخش صوت با متن همگام، تکرار یک مصراع یا بازه، تغییر سرعت و گام
- **استخراج هوشمند متن و زمان‌بندی** از فایل صوتی یا ضبط میکروفون (با سرور واسط سازگار با OpenAI)
- کپی سریع متن، کپی با زمان (قالب LRC) یا کپی تک‌خط از پیش‌نمایش استخراج
- ویرایشگر همگام‌سازی دستی، نشانه‌گذاری و یادداشت روی هر مصراع، حالت منبر
- انتخاب صوت از حافظهٔ گوشی و به‌خاطر سپردن مکان توقف هر اثر
- پشتیبان‌گیری و بازیابی کامل آثار

## دانلود و نصب

از بخش **[Releases](../../releases)** فایل `TaninMaddahi-release.apk` را دانلود و نصب کنید
(اجازهٔ «نصب از منابع ناشناس» را برای مرورگر یا مدیر فایل فعال کنید).

## تنظیم سرور واسط برای استخراج هوشمند

داخل برنامه: **تنظیم سرور واسط**

| فیلد | مقدار |
|---|---|
| Base URL | آدرس سرور شما، مثلاً `[https://generativelanguage.googleapis.com/v1beta/openai/]` |
| API Key | کلید سرور (می تواند رایگان و برای استفاده شخصی از `[https://aistudio.google.com/app/apikey]`دریافت کنید.) |
| Model | مثلاً `gemini-3.5-flash` یا نام مدل پشتیبانی‌شده در حساب شما |
| نوع درخواست | «خودکار» یا Chat Completions |

سرور باید سازگار با OpenAI باشد و ورودی صوتی (`input_audio`) را بپذیرد؛
برای مثال [openai-gemini](https://github.com/PublicAffairs/openai-gemini) که Gemini را به قالب OpenAI تبدیل می‌کند.

نکته‌ها:

- برنامه صوت را قبل از ارسال به تکه‌های ۶۰ ثانیه‌ای (مونو، ۱۶kHz) تبدیل و بلندی آن را یکنواخت می‌کند، چون سرور ممکن است بدنهٔ درخواست را حداکثر **۴٫۵ مگابایت** می‌پذیرد.
- مسیر `audio/transcriptions` (Whisper) در بسیاری از سرورهای واسط پیاده‌سازی نشده است؛ مدل Gemini با Chat Completions توصیه می‌شود.
- مدل‌های سبک (lite) در رونویسی فارسی دقت کمتری دارند؛ برای دقت بیشتر مدل قوی‌تر انتخاب کنید.
- کلید API فقط روی گوشی شما ذخیره می‌شود.

## حریم خصوصی

آثار، یادداشت‌ها و تنظیمات روی دستگاه شما ذخیره می‌شود. فقط هنگام «استخراج هوشمند» صوت (پردازش‌شده) به سرور واسطی که خودتان وارد کرده‌اید ارسال می‌شود.
